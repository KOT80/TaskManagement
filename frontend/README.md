# TaskManagement — Frontend (тестовое задание)
Разработать простое веб-приложение для управления задачами.

Frontend часть приложения тестового задания для управления задачами.
## Функциональность: 
Страница со списком задач:
Отображение названия задачи
Отображение даты создания
Отображение статуса выполнения
Добавление новой задачи:
Title
Description
Действия над задачей:
Отметить как выполненную
Удалить задачу



## Технологии

- **Angular 21** — основной фреймворк.
- **TypeScript** — типизация и структура приложения.
- **Angular Signals** — управление состоянием и реактивное обновление интерфейса.
- **RxJS** — работа с асинхронными HTTP-запросами.
- **Angular Forms** — работа с формами создания и редактирования задач.
- **SCSS** — стилизация интерфейса.
- **HttpClient** — взаимодействие с backend API.

## Требования

Для локального запуска понадобятся:

- Node.js — версия, совместимая с используемой версией Angular CLI.
- npm.
- Запущенный backend TaskManagement, доступный по адресу API, указанному в настройках frontend.

## Запуск проекта

Перейди в каталог frontend:

```bash
cd frontend
```

Установить зависимости:

```bash
npm install
```

Запустить приложение :

```bash
npm start
```

http://localhost:4200/

## Настройка API

Адрес backend API задаётся в конфигурации окружения приложения. Сейчас сервис задач использует базовый адрес из `environment.apiUrl` и добавляет к нему маршрут `/tasks`.

Текущий адрес API:

```text
https://localhost:44381/api/v1
```

Перед запуском необходимо, чтобы backend был доступен по этому адресу и HTTPS-соединение настроено корректно.


Назначение основных частей:

- **`core/errors`** — общие утилиты обработки ошибок API.
- **`models/api`** — типы данных, используемые при обмене с backend.
- **`models/task.model.ts`** — внутренняя модель задачи, используемая приложением.
- **`mappers`** — явное преобразование API DTO во внутренние модели.
- **`services`** — HTTP-запросы к backend.
- **`state`** — состояние задач, загрузка данных, фильтрация и CRUD-операции.
- **`pages`** — страницы и пользовательский интерфейс.
